# 🌸 The Pink Dining Guide – Web Design Project

## Uppgiftsbeskrivning
I detta projekt har jag byggt en **rosa-inspirerad hemsida för restauranger och matupplevelser** med hjälp av **HTML och CSS**.  
Hemsidan kombinerar ett lekfullt och elegant tema med responsiv design för både mobil, surfplatta och desktop.

Webbplatsen visar:

* Restauranger och caféer med rosa inredning
* Menyer och matbilder med estetiskt fokus
* Kontaktformulär för besökare att skicka meddelanden

---

## 📁 Projektstruktur

```
project/
├── Projekt.html       # Startsida med restauranginfo
├── prov.html          # Kontaktformulär
├── Projekt.css        # Stil för startsidan
├── prov.css           # Stil för kontaktformulär
└── Images/            # Bilder som används på sidan
```

---

## 🎨 Design och stil

* Rosa-tema med harmoniska färger (#fdeef5, #f4c2d7, #fff5fa, #d56a9a)  
* Rundade hörn och mjuk layout  
* Typsnitt: Brush Script MT för rubriker, Verdana för brödtext  
* Responsiv design med media queries  
* Bilder med rundade hörn och proportioner som matchar layouten  

---

## 🧩 Funktioner

* Tydlig navigation mellan startsida, om oss och kontakt  
* Kontaktformulär med validering (via [Web3Forms](https://web3forms.com))  
* Flexibel layout med aside och sektion för text och bilder  
* Mobilvänlig design: inputfält och bilder anpassas automatiskt
